# Paint Store V0 — GitHub Pages Web App

Static, local-first inventory and sales app.

## Deploy
Upload `index.html`, `manifest.json`, and `sw.js` to a GitHub repository, then enable **Settings → Pages → Deploy from branch → main / root**.

The app stores data in the browser's local storage. It does not require a server or database.

## V0
- Product search and cart
- Quantity typing
- Paid / partial / credit sales
- Automatic stock reduction
- Customer outstanding balances
- Inventory and low-stock view
- Price updates
- Basic sales dashboard
- JSON backup/import
- PWA/offline cache
